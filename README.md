# Roomverse 🏠🤝

**Roomverse** is a roommate-matching web application designed to help students and young professionals find compatible living partners and suitable housing. By matching users based on shared preferences, lifestyle habits, and budget requirements, Roomverse simplifies the process of finding the right roommate.

---

## ✨ Features

- **User Preference Questionnaire:** Interactive onboarding to collect lifestyle habits, study/work schedules, cleanliness preferences, and room requirements.
- **Smart Matching System:** Algorithmic filtering to connect users with compatible potential roommates.
- **Search & Discovery Dashboard:** Browse through roommate profiles and available living spaces with filtering options.
- **Responsive Layout:** Clean, intuitive UI tailored for both desktop and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** JavaScript (ES6+), HTML5, CSS3
- **Backend / Database:** Node.js, Express, MongoDB
- **Version Control:** Git, GitHub

## 🚀 Getting Started

Follow these instructions to get a local copy of the project up and running for development and testing.

### Prerequisites

- [Node.js](https://nodejs.org/) (v14.x or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [MongoDB](https://www.mongodb.com/) (Local instance or MongoDB Atlas connection)

### Installation

1. **Clone the repository:**
   `git clone https://github.com/leealtair/Roomverse.git`
   `cd Roomverse`

2. **Install dependencies:**
   `npm install`

3. **Environment Setup:**
   Create a `.env` file in the root directory and add your environment variables (`PORT=5000`, `MONGO_URI=your_mongodb_connection_string`).

4. **Run the Application:**
   `npm start`
